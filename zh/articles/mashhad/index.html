马什哈德

中国到马什哈德海关的 TIR 卡航

文章目录
  1. 为什么比德黑兰短
  2. 萨拉赫斯之后
  3. 常见问答

马什哈德海关是这条走廊的常规 CPT / DAP 目的地，与德黑兰西关、阿普林陆港并列。卡车从乌恰或霍尔果斯 TIR 施封出境，萨拉赫斯入境。自乌恰起算，直达车目前 18–21 天到马什哈德保税库——因为它不再西行去德黑兰。仓到关。马什哈德清关行拿入库单；我们不到巴扎。

  • 目前 18–21 天自乌恰至马什哈德海关（直达车；换装 24–28 天）
  • 与德黑兰同一条 TIR 走廊：吉 — 乌兹 — 土库曼 — 萨拉赫斯，然后北上马什哈德而不是西去德黑兰
  • 仓到关 · CPT / DAP · 马什哈德清关行清关缴税
  • 汽运只接整车，不接拼箱

为什么比德黑兰短

德黑兰西关直达车自乌恰 21–23 天，是因为伊朗境内还要西行到首都。马什哈德靠近萨拉赫斯口岸。中亚国际段相同，省下的是伊朗境内，不是另一条中亚路。乌恰线仍有吉尔吉斯斯坦 0.4% 过境税。霍尔果斯到马什哈德时效询价，不含 0.4%。

国内集货仓 → 乌恰口岸报关施封（TIR 关锁 + 电子封签） → 吉尔吉斯斯坦、乌兹别克斯坦、土库曼斯坦一票 TIR 过境 → 萨拉赫斯入境 → 目的海关保税库，出具海关入库单（Ghabz-e Anbar）交清关行。直达车中途仅在布哈拉换装一次；换装车在奥什和布哈拉各换装一次，运费更低但天数更长。TIR 只减少开箱与换装次数，并非全程不换装，也不改变时效和运价。乌恰线过境吉尔吉斯斯坦，按 cargo invoice 货值加收 0.4% 过境税——是税不是运费，报价不含，客户另付。霍尔果斯线改走哈萨克斯坦，一律不涉及 0.4%，时效请询价。吐尔尕特、阿拉山口目前不做。

萨拉赫斯之后

常规 TIR 在萨拉赫斯不开箱。挂车开到马什哈德海关保税库。仓库把入库单交给订舱时写明的马什哈德清关行。之后 ASYCUDA、税金、市内车是清关行的档案——和德黑兰同一分工，换一个办公室。买家在马什哈德或东部，停在这里就不必进德黑兰库再倒车往东。

网上不挂运价。要报价发三样:始发仓;目的地(CPT / DAP 到德黑兰西关，阿普林或马什哈德以报价确认为准；或萨拉赫斯、洛特法巴德等目的地场站);货物数据——HS 编码、总重 KG、体积 CBM。

常见问答

自乌恰到马什哈德多少天?

自乌恰口岸起算：直达车目前 18 至 21 个自然日到马什哈德海关保税库；换装车 24 至 28 天。国内段至乌恰通常 7 天内，另行计算。非承诺时效。

做门到门吗?

不做。可报两种交付方式：CPT / DAP 到德黑兰西关、马什哈德海关或阿普林陆港保税库，或场站到场站，交到伊朗边境萨拉赫斯或洛特法巴德场站。两种方式均由收货人的持牌清关行缴税、清关和境内提货；不做 DDP。

马什哈德的货能跟德黑兰整车混装吗？

不能。汽运只接整车。马什哈德货走马什哈德订舱。混上德黑兰挂车，等于清关行在德黑兰提货再东运——多花钱多花时间，不是捷径。

马什哈德货走洛特法巴德入境吗?

CPT / DAP 到马什哈德或德黑兰西关时，乌恰线车辆通常经萨拉赫斯入境。场站到场站订舱可交到萨拉赫斯或洛特法巴德边境场站，由买方清关；请在施封前的询价里写明清关行使用哪个场站。

接拼箱吗？

不接。汽运只做整车，在新疆装车。没有义乌 / 深圳拼箱班期。
