货在新疆集完，出境走乌恰还是霍尔果斯

文章目录
  1. 先集货，再选口
  2. 中亚卸还是送到伊朗海关
  3. 乌恰和霍尔果斯差在哪
  4. 常见问题

CargoIranTruck 讲的是货在新疆集完再上路，不是华东工厂门口发车。从新疆上路介绍两条走廊；这一页写集完货之后怎么选出境口。

  • 从新疆仓 / 场站上路，不是工厂装车
  • 乌恰经吉国，有过境税 0.4%；霍尔果斯经哈国，没有这笔税
  • 只有乌恰线从口岸起算写天数；霍尔果斯不写天数
  • 塔吉克斯坦不是这两条已开线路的目的地

先集货，再选口

货先到始发仓或出境监管场地，再从乌恰或霍尔果斯出去。在售两条：乌恰 新疆 → 吉尔吉斯斯坦 → 乌兹别克斯坦 → 土库曼斯坦 → 伊朗；霍尔果斯 新疆 → 哈萨克斯坦 → 乌兹别克斯坦 → 土库曼斯坦 → 伊朗。吐尔尕特、阿拉山口目前不走。

中亚卸还是送到伊朗海关

集完货先写清：这票在过境国卸，还是送到伊朗海关。送到伊朗，对外可报马什哈德海关或德黑兰西关，入境萨拉赫斯，清关买方办。仓到关，CPT / DAP，不到门，不做 DDP。中途卸，把场地写进询价；目的地空着，不出书面报价。

乌恰和霍尔果斯差在哪

乌恰走吉国，有过境税 0.4%。是税不是运费，报价不含，客户另付。霍尔果斯走哈国，没有这笔 0.4%。计税基数页面不写。

只有乌恰线从口岸起算对外写天数：目前马什哈德直达 18–21 天 / 换装 24–28 天，德黑兰直达 21–23 天 / 换装 26–30 天。当前运行区间，不是保证。霍尔果斯不写天数。篷车，不是集装箱。页面不报死价。

常见问题

从工厂装车吗？

不。新疆仓 / 场站。仓到关，不做门到门，不做 DDP。

中亚五国都是在售目的地吗？

不。两条已开走廊经吉国或哈国；塔吉克斯坦不是这两条线的目的地。

霍尔果斯写几天？

不写。要书面询价。
