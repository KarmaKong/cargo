从新疆上路：两条走廊到伊朗和中亚

文章目录

  2. 时效和 0.4%
  3. 常见问答

这个站讲的是从新疆出发。卡车不是从工厂门口开：收货在仓 / 场站，交在目的场站。不做门到门，不做 DDP。

  • 乌恰线：新疆 → 吉尔吉斯斯坦 → 乌兹别克斯坦 → 土库曼斯坦 → 伊朗
  • 霍尔果斯线：新疆 → 哈萨克斯坦 → 乌兹别克斯坦 → 土库曼斯坦 → 伊朗
  • 对外时效只适用于乌恰线，从口岸起算；霍尔果斯不写天数
  • 吉国 0.4% 是税，只在乌恰线，报价不含

从新疆出发的两条走廊

吐尔尕特、阿拉山口目前不走。车型是篷车，不是集装箱。伊朗侧清关口岸是萨拉赫斯或洛特法巴德，清关由买方办理。

TIR 开箱换车更少，不是没有；不改变时效和运费。在途没有轨迹接口，节点靠人工更新。

时效和 0.4%

对外时效只适用于乌恰线，从口岸起算（2026-09-07）：萨拉赫斯、洛特法巴德直达 15–18 天、换装 21–24 天；马什哈德直达 18–21、换装 24–28；德黑兰直达 21–23、换装 26–30。霍尔果斯线不写天数。

乌恰线另有一笔不是运费的钱：吉国过境 0.4%。是税，报价不含，客户另付。霍尔果斯线不经吉尔吉斯，没有这一笔。计税基数这里不写死。

页面不报死价。把新疆侧起运仓、目的场站、货名、毛重和体积发邮件，正式报价带有效期。

常见问答

卡车从工厂门口开吗？

不。仓 / 场站到目的场站。不做门到门，不做 DDP。

塔吉克斯坦是这条线的目的地吗？

在售两条走廊经吉尔吉斯或哈萨克，再经乌兹别克、土库曼到伊朗。塔吉克斯坦不是这两条已开线路的目的地。

霍尔果斯写几天？

不写。表只适用于乌恰线。

0.4% 是运费吗？

不是。是吉国过境税，只在乌恰线，报价不含，客户另付。霍尔果斯线没有。
