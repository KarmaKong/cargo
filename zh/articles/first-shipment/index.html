第一次发中国到伊朗:一张清单走完

文章目录

  2. 保险按贸易术语
  3. 常见问答

2026-09-04

给第一次走这条线的工厂或外贸公司。本线是中国集货仓到德黑兰海关保税库——仓到关,不是门到门。

  • 选始发仓(义乌 / 深圳 / 广州)和目的海关(德黑兰西关 / 阿普林 / 马什哈德)
  • HS 编码对齐;发票、装箱单、合同要与实货一致
  • 锂电 / 化工品第一条就申报——附 16 项 MSDS 与 UN 包装证明
  • 卡车到之前先定好伊朗清关行,凭 Ghabz-e Anbar 在 ASYCUDA 清关
  • 预留自乌恰口岸起算 21–23 天到保税库,另加国内段(~7 天)与清关行的清关时间
  1. 选始发仓(义乌 / 深圳平湖 / 广州)和目的海关(德黑兰西关 / 阿普林陆港 / 马什哈德海关)
  2. HS 编码对齐;商业发票、装箱单、合同的货名、件数、货值与实货一致
  3. 带锂电 / 化工的货,询盘第一条就写明,附 16 项 MSDS 与 UN 包装证明
  4. 卡车到达前定好伊朗持牌清关行,凭海关入库单(Ghabz-e Anbar)在 ASYCUDA 清关缴税
  5. 时间预算:自乌恰口岸起算 21–23 天到德黑兰西关保税库,另加国内段(~7 天)与清关行清关、提货时间

仓到关,不是到门

交付到保税库为止。缴税、清关、境内配送是收货人清关行的事。场站之后谁短驳,合同里写清。

保险按贸易术语

谁承担风险谁投保。陆运通道不过霍尔木兹海峡,没有海运战争险附加费。我们随货带 CMR 一切险到德黑兰海关。

网上不挂运价。要报价发三样:始发仓;目的海关(德黑兰西关 / 阿普林 / 马什哈德);货物数据——HS 编码、总重 KG、体积 CBM。

常见问答

第一次询价发什么?

三样:始发仓;目的海关;货物数据(HS 编码、总重 KG、体积 CBM)。锂电 / 化工附 MSDS。

卡车发车前就要定好伊朗清关行吗?

是。货到保税库出具 Ghabz-e Anbar 后要立刻交给清关行,提前定好不耽误。

是门到门吗?

不做。交付到德黑兰海关保税库;缴税、清关、境内提货由收货人的持牌清关行办。

从发车到清关完要多久?

自乌恰口岸起算 21–23 天到保税库(另加国内段,通常 7 天内);清关时间另计,取决于单证是否齐全和清关行效率。
