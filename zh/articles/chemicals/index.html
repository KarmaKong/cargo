聚合物粒料与非危化工卡车发伊朗

文章目录
  1. 路线
  2. MSDS、吨袋，以及不装什么
  3. 常见问答

聚合物粒料、色母、非危化工走公路发伊朗。在新疆装车，经乌恰或霍尔果斯口岸以 TIR 密封帘布车出境。乌恰线直达车中途仅在布哈拉换装一次，目前 21–23 天抵德黑兰西关；天数自口岸起算。仓到关。完整 16 项 MSDS 要在订车前给，不是施封后再补。

  • 目前 21–23 天自乌恰至德黑兰西关（直达车；换装 26–30 天）；马什哈德直达 18–21 天
  • 仓到关 · CPT / DAP · 由收货人清关行在海关清关缴税提货
  • 本帘布车只接非危聚合物和化工；3 / 8 / 6.1 类另议或拒装
  • 询价第一行写 16 项 MSDS 与 UN 编号（或“未分类”）

路线

国内集货仓 → 乌恰口岸报关施封（TIR 关锁 + 电子封签） → 吉尔吉斯斯坦、乌兹别克斯坦、土库曼斯坦一票 TIR 过境 → 萨拉赫斯入境 → 目的海关保税库，出具海关入库单（Ghabz-e Anbar）交清关行。直达车中途仅在布哈拉换装一次；换装车在奥什和布哈拉各换装一次，运费更低但天数更长。TIR 只减少开箱与换装次数，并非全程不换装，也不改变时效和运价。乌恰线过境吉尔吉斯斯坦，按 cargo invoice 货值加收 0.4% 过境税——是税不是运费，报价不含，客户另付。霍尔果斯线改走哈萨克斯坦，一律不涉及 0.4%，时效请询价。吐尔尕特、阿拉山口目前不做。

MSDS、吨袋，以及不装什么

PE、PP、PVC、ABS 粒料、色母、塑料助剂，以及公路未列为危险品的工业化学品。吨袋（FIBC）和 25 公斤袋必须打托；散袋收货口拒收，因为布哈拉是叉车换装。“粒料，不危险”不够——MSDS 上要有 CAS / UN 号、包装类别、闪点、是否对环境有害。3 类易燃液体、8 类腐蚀、6.1 类毒性，以及要罐车或 ADR 车牌的货，不装这条普货帘布车。锂电池（UN 3480 / 3481）例外：须单独申报，提供 16 项 MSDS 与 UN 包装文件，逐票以正式报价确认后承运。

网上不挂运价。要报价发三样:始发仓;目的地(CPT / DAP 到德黑兰西关，阿普林或马什哈德以报价确认为准；或萨拉赫斯、洛特法巴德等目的地场站);货物数据——HS 编码、总重 KG、体积 CBM。

常见问答

从乌恰口岸到德黑兰海关要多少天？

时效自乌恰口岸起算：直达车目前 21 至 23 个自然日抵德黑兰西关海关保税库，换装车 26 至 30 天；到马什哈德直达 18 至 21 天，换装 24 至 28 天。直达车中途仅在布哈拉换装一次，换装车在奥什和布哈拉各换装一次。在新疆装车；国内段至口岸如有，单独计算。霍尔果斯线时效请询价。以上为当前实际运行区间，随口岸通关情况浮动，非承诺时效。

做门到门吗?

不做。可报两种交付方式：CPT / DAP 到德黑兰西关保税库（马什哈德或阿普林以正式报价确认为准），或场站到场站，交到伊朗边境萨拉赫斯或洛特法巴德场站。两种方式均由收货人的持牌清关行缴税、清关和境内提货；不做 DDP。

接危险品吗?

只有 MSDS 显示公路未分类，或已经另订危货车，才接。锂电池（UN 3480 / 3481）在询价时申报、提供 16 项 MSDS 与 UN 包装文件并经正式报价确认后可接。不要把危包桶混进整车普货。瞒报危货在始发仓卸下，费用发货人承担。

MSDS 够伊朗进口用吗?

够我们装车。伊朗清关——备案、标准、HS 是否要许可——是收货人清关行拿到入库单之后的事。车到之前把同一份 MSDS 发给清关行。

接拼箱吗？

不接。汽运只做整车，在新疆装车。没有义乌 / 深圳拼箱班期。
