冬天中国至伊朗/中亚汽运：口岸、低温与计划弹性

冬天走新疆到伊朗、哈萨克斯坦、吉尔吉斯斯坦、乌兹别克斯坦、塔吉克斯坦或土库曼斯坦的公路，决策不在“今年会不会特别冷”，而在口岸能不能走、货能不能冻、包装能不能换装、以及交付点停在场站还是德黑兰西关。网上不挂运价，也不预告封路日期。侧帘 / 篷布半挂车，单车最高 96 m³、25 吨；吐尔尕特、阿拉山口目前不做。

  • 两条出境口都可询：乌恰 / 伊尔克什坦（经吉尔吉斯，0.4% 过境税另付）与霍尔果斯（经哈萨克斯坦，无该税）
  • 低温会改变柴油、电瓶、薄膜和液体的状态；网页不给出具体气温或封路预报
  • 交付只有两种已确认方式：场站到场站，或伊朗 CPT / DAP 到德黑兰西海关监管仓
  • 锂电池须在询价时申报；未申报拒收。运价与时效以正式报价为准，非承诺

冬季怎么选口岸和路线

新疆两个出境口岸：乌恰 / 伊尔克什坦，经吉尔吉斯斯坦、乌兹别克斯坦、土库曼斯坦到伊朗；霍尔果斯，经哈萨克斯坦、乌兹别克斯坦、土库曼斯坦到伊朗。中亚五国也可作为目的地，路线安排和时效随正式报价提供。冬季选口岸，看的是当时可走的路段、口岸作业窗口、换装点是否开放，以及买方要的交付点——不是看哪一条“冬天更快”。

乌恰线过境吉尔吉斯斯坦，按 cargo invoice 货值加收 0.4% 过境税，是税不是运费，报价不含，客户另付。霍尔果斯线走哈萨克斯坦，一律不涉及 0.4%。税负、交付点和当时路况，都是决策因素；不要把霍尔果斯写成冬季默认，也不要把乌恰写成不能走。TIR 可选：起运地封关，可减少倒装次数但并非零倒装，也不会单独改变时效或价格。直达车在布哈拉倒装一次；倒装车在奥什和布哈拉倒装，或在伊朗边境倒装。冬季若某一换装场积雪或排队，换装次数会放大等待，这是计划问题，不是车型承诺。

低温对车辆、货物和包装

低温本身不是一条新航线，它改变的是车上和货上已经存在的物理状态。柴油在低温下流动性下降，车辆预热和停驶后再启动需要更长时间，这会拉长口岸外排队，而不是改写报价里的立方和吨位。电瓶容量在低温下下降，定位和封签设备若电量不足，跟踪节点会断，不是货丢了。这些是运行层的影响，站点不给出某月某日的气温结论。

货物侧更常见的是包装失效，不是“冻坏品名”。拉伸膜和部分塑料护角变脆，捆带收缩后再回温会松；纸箱吸湿后在换装叉车上塌角。液体、乳胶、水性涂料、部分胶水和食品如果合同禁止冻结，必须在询价里写明，不要等到装车当晚口头补一句。从寒冷路段进入相对温暖的库区，箱内空气升温，水汽会在薄膜内侧结露——防潮和防冻经常是同一套包装要同时处理的两件事。

侧帘车不是保温柜，也不是冷藏车。网页不承诺全程恒温。怕冻、怕潮、怕结露的货，要用托盘、缠膜、干燥剂、必要时内衬，使布哈拉或奥什的叉车换装仍能整托作业。木箱要能叉；散纸箱、无底座软包，始发仓会停，冬天不会因为赶路而放行。

防冻、防潮、装卸与加固

防冻先看货物本身：哪些液体、胶体、电芯或精密件在文件上写了储存温度。没有文件就不要口头说“不怕冻”。防潮看换装：托盘离地、缠膜封顶、护角护边，唛头两面都有，且与装箱单一行对一行。干燥剂放在密封层内侧才有用；只在帘布外侧罩一层薄膜，换装时会被撕掉。

装卸和加固在冬天要多做一遍检查，不是多收一项“冬季服务”。侧帘拉开后，积雪和融水不要进托盘缝；捆带、角钢、木撑在低温下是否还咬得住，装完要看，过境换装后再看。渗漏桶、无唛混装、叉不起来的木箱，始发仓直接拒收。加固、吊装费用报价默认不含，需要单独写进询价。依法需要强制检验的货物，缺检验文件则检验费用另行报价。

雪冰与封路：计划要留弹性

积雪、结冰、能见度不足或过境国临时封路，会让车停在口岸外、换装场或途中，而不是停在网页上的天数表里。乌恰线路的伊朗参考区间只适用于该线路的当前运行，且明确为非承诺时效；霍尔果斯时效随报价提供。冬季询价时，把货物备妥日期写成可窗口，而不是单一天；买方清关行也要按窗口等入库单，而不是按日历倒推提货日。

封路是否发生、哪一天发生，以口岸和过境路段当时的通告为准。本页不列出“某山口每年某月关闭”之类没有核对日期的结论，也不把弹性天数写成新的承诺区间。正式报价会带编号和有效期；有效期内路况变化，以新的书面确认为准。保险不包含在运费报价内，货损程序见索赔说明，不要把天气等待自动理解成货损。

普货与锂电池怎么申报

普通货物可以询。品名、HS 编码、件数、毛净重、体积要在询价里一次写清，不要用“配件一批”代替。3 类易燃液体、8 类腐蚀、6.1 类毒性，以及要罐车或 ADR 车牌的货，不装这条普货侧帘车；是否可另议，以正式报价为准，网页不预先承诺。

锂电池（UN 3480 / UN 3481）必须在询价时申报，并提供 16 项 MSDS 与 UN 包装文件，每票以正式报价确认。未申报的锂电池仍然拒收。充电宝、电芯混进“普货”在收货口就会停。低温不改变这一申报规则：冬天也要先有文件，再谈装车。MSDS 够我们判断能不能装；伊朗进口许可、标准和清关，是收货人清关行在拿到入库单之后的事。

询价资料，以及交付边界

网上不挂运价。询价发到 sales@cargoirantruck.com，或走询价表。请一次给齐：出境口岸（乌恰 / 伊尔克什坦、霍尔果斯，或不确定）、目的地国家与城市、交付方式、货物描述、HS 编码、体积（m³）、重量、车辆数量、货物备妥日期。锂电池加上 UN 编号、16 项 MSDS、UN 包装文件。包装照片、是否禁止冻结、是否怕潮，有就写上。在新疆仓储、装车并办理出口申报；正式报价通过邮件发送，附报价编号和有效期。

已确认的交付只有两种，冬天也不扩大范围。场站到场站：仓库 / 场站 → 目的地场站；伊朗货物由买方在萨拉赫斯或洛特法巴德清关。伊朗 CPT / DAP：送到德黑兰西海关监管仓，由收货人的清关行清关、缴税、境内提货。两种方式都不提供门到门、DDP 或目的地清关。马什哈德海关、阿普林陆港不在已确认的常规交付点内，需要时按需报价、以正式报价逐票确认。报价包含全程运输、中国境内仓储、装车、中国出口申报和境外中转代理费用；不含目的地清关、保险、检验、加固 / 吊装、境外额外费用和超限费用。

常见问答

冬天是不是必须走霍尔果斯？

不是。乌恰 / 伊尔克什坦和霍尔果斯两条出境口岸都在服务范围内。冬季选哪一条，看当时口岸与过境路段是否可走、吉尔吉斯斯坦 0.4% 过境税是否可接受、以及交付点是场站还是德黑兰西关。网页不预告封路日期，也不把某一口岸写成冬季默认。

站点上的伊朗参考天数，冬天还算数吗？

那些数字只适用于乌恰 / 伊尔克什坦线路的当前运行区间，不是承诺时效；霍尔果斯时效随报价提供。冬季还要为积雪、结冰、封路和口岸排队预留弹性。具体以正式报价上的区间为准，报价会注明编号和有效期。

做门到门吗？

不做。可报两种交付方式：场站到场站，交到目的地场站，伊朗货物由买方在萨拉赫斯或洛特法巴德清关；或伊朗 CPT / DAP 送到德黑兰西海关监管仓，由收货人的清关行清关。两种方式都不含门到门、DDP 或目的地清关。

锂电池冬天能发吗？

可以询。锂电池（UN 3480 / UN 3481）必须在询价时申报，并附 16 项 MSDS 和 UN 包装文件，每票以正式报价确认。未申报的锂电池拒收。低温下电芯与包装都要按文件说明处理，不要混进普货。

询价要准备哪些资料？

出境口岸（乌恰 / 伊尔克什坦、霍尔果斯，或不确定）、目的地国家与城市、交付方式（场站到场站，或伊朗 CPT / DAP 德黑兰西关）、货物描述、HS 编码、体积、重量、车辆数量、货物备妥日期。锂电池还要 UN 编号、16 项 MSDS 和 UN 包装文件。包装照片、是否怕冻或怕潮，有就一并写上。
