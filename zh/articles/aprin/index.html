阿普林陆港作为中伊 TIR 目的地

文章目录

  2. 订舱时怎么写成目的海关
  3. 常见问答

阿普林陆港（Bandar-e Khoshk-e Aprin）是常规 CPT / DAP 目的地，与德黑兰西关、马什哈德海关并列。卡车在新疆装车，TIR 密封帘布车经乌恰或霍尔果斯出境、萨拉赫斯入境。交到阿普林保税设施，不是德黑兰街上。你指定的清关行领取入库单。到阿普林的时效按票询——不要把 21–23 天德黑兰西关数字直接抄到阿普林订舱上。

  • 常规 CPT / DAP 目的地；仓到关；只接整车
  • 同一中国出境口和萨拉赫斯入境；伊朗境内最后一段到阿普林，不是 Gomrok Gharb
  • 到阿普林时效询价——不是公布的乌恰–德黑兰西关区间
  • 询价第一行把目的海关写成阿普林；德黑兰挂车不等于送到阿普林

阿普林和德黑兰西关怎么并列

德黑兰西关（Gomrok Gharb）是公布 21–23 天数字的默认保税库。阿普林是德黑兰以西的陆港，清关行和后续铁路/卡车在那里的进口商用。不是到门，不是 DDP。TIR 单证本在你订的阿普林设施结关，入库单在那里出。如果买家清关行只做西关，把车送到阿普林等于制造一次他们没计划的转库——乌恰施封前确认办公室。

国内集货仓 → 乌恰口岸报关施封（TIR 关锁 + 电子封签） → 吉尔吉斯斯坦、乌兹别克斯坦、土库曼斯坦一票 TIR 过境 → 萨拉赫斯入境 → 目的海关保税库，出具海关入库单（Ghabz-e Anbar）交清关行。直达车中途仅在布哈拉换装一次；换装车在奥什和布哈拉各换装一次，运费更低但天数更长。TIR 只减少开箱与换装次数，并非全程不换装，也不改变时效和运价。乌恰线过境吉尔吉斯斯坦，按 cargo invoice 货值加收 0.4% 过境税——是税不是运费，报价不含，客户另付。霍尔果斯线改走哈萨克斯坦，一律不涉及 0.4%，时效请询价。吐尔尕特、阿拉山口目前不做。

订舱时怎么写成目的海关

询价表选阿普林陆港，不要选德黑兰西关。HS、总重公斤、体积立方仍必填。汽运只接整车。询价表选阿普林陆港，不要选德黑兰西关。德黑兰卸完之后在伊朗境内转库，是清关行的车，不是我们的。

网上不挂运价。要报价发三样:始发仓;目的地(CPT / DAP 到德黑兰西关，阿普林或马什哈德以报价确认为准；或萨拉赫斯、洛特法巴德等目的地场站);货物数据——HS 编码、总重 KG、体积 CBM。

常见问答

阿普林比西关更快吗?

没有公布数字。按那班车问阿普林区间。不要假定它继承自乌恰到 Gomrok Gharb 的 21–23 天。

做门到门吗?

不做。可报两种交付方式：CPT / DAP 到德黑兰西关、马什哈德海关或阿普林陆港保税库，或场站到场站，交到伊朗边境萨拉赫斯或洛特法巴德场站。两种方式均由收货人的持牌清关行缴税、清关和境内提货；不做 DDP。

我的西关清关行能在阿普林提货吗?

只有该清关行在阿普林有资质。很多德黑兰清关行只做一个现场。订舱写清关行名字和设施，避免入库单开到错误窗口。

0.4% 还收吗?

乌恰 / 伊尔克什坦经吉尔吉斯斯坦的仍收，与伊朗目的地无关。霍尔果斯线不收。

接拼箱吗？

不接。汽运只做整车，在新疆装车。没有义乌 / 深圳拼箱班期。
