主要目的地

新疆至伊朗公路货运

可选择乌恰 / 伊尔克什坦或霍尔果斯线路。以下参考时效仅适用于乌恰线路。

乌恰 / 伊尔克什坦

  1. 01新疆
  2. 02吉尔吉斯斯坦
  3. 03乌兹别克斯坦
  4. 04土库曼斯坦
  5. 05伊朗

经过吉尔吉斯斯坦。直达车为布哈拉倒装一次；倒装车在奥什和布哈拉，或伊朗边境倒装。

霍尔果斯

  1. 01新疆
  2. 02哈萨克斯坦
  3. 03乌兹别克斯坦
  4. 04土库曼斯坦
  5. 05伊朗

经过哈萨克斯坦。时效随正式报价提供。此线路不适用吉尔吉斯斯坦0.4%税费。

乌恰 / 伊尔克什坦线路

伊朗运输时效 · 仅适用于乌恰 / 伊尔克什坦线路

目的地直达车倒装车
萨拉赫斯 / 洛特法巴德15–18 天21–24 天
马什哈德18–21 天24–28 天
德黑兰西关21–23 天26–30 天

直达车：布哈拉倒装一次。倒装车：奥什和布哈拉倒装，或根据安排在伊朗边境倒装。霍尔果斯时效随报价提供。

车辆与交付范围

侧帘 / 篷布半挂车，单车最高96 m³、25吨；承运普通货物，以及申报并提供 16 项 MSDS 与 UN 包装文件、逐票确认的锂电池（UN 3480 / 3481）。场站到场站：买方在萨拉赫斯或洛特法巴德清关。CPT / DAP 可选：交到德黑兰西关、马什哈德海关或阿普林陆港保税库，由收货人的清关行清关。不含门到门、DDP或目的地清关。

伊朗线路报价范围

报价包含

  • 全程运输费用
  • 中国境内仓储
  • 装车
  • 中国出口申报
  • 境外中转代理费用

报价不包含

  • 目的地清关
  • 保险
  • 检验费用
  • 加固 / 吊装
  • 境外额外费用
  • 超限费用

税费说明

吉尔吉斯斯坦0.4%税费仅适用于经吉尔吉斯斯坦中转的乌恰 / 伊尔克什坦线路，由客户支付；霍尔果斯线路不适用。
