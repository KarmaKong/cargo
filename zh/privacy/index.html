本条款说明当你使用本网站或与我们联系时,CargoIranTruck(以下称“我们”)处理哪些数据。

本网站为静态站

本站不设置 Cookie。不投放广告,不使用跨站追踪。

统计分析

本网站当前未启用 GoatCounter 或其他访客统计脚本。联系按钮会打开相应的第三方服务，其数据处理方式以该服务的隐私政策为准。

托管

本站由 GitHub Pages 提供服务。与任何 Web 服务器一样,GitHub 会为交付页面和安全目的接收标准请求数据(你的 IP 地址、User-Agent 及请求的网址),依据 GitHub 的隐私声明处理。

当你与我们联系

当你通过邮件、WhatsApp、Telegram 或本站询价表（会在你的邮件应用中打开一封发给 sales@cargoirantruck.com 的信）联系我们时,我们会收到你发送的信息,通常包括姓名、公司、联系方式及货物或运输明细。若你使用 WhatsApp 或 Telegram,该渠道还适用其各自的隐私政策。

用途

仅用于回复你的询问、制作报价和安排运输。我们不出售你的数据,未经你同意不用于无关的营销。

共享对象

我们仅将运输明细共享给执行运输所必需的各方:我们的司机与调度、过境国及海关当局,以及(在你指示时)收货人的清关行。

保存期限

询价与运输记录在业务关系存续期间保存,并保存至会计与法律留存所需的期限,之后删除。

你的权利

你可要求我们访问、更正或删除你已发送给我们的个人数据。请发送邮件至 sales@cargoirantruck.com。

数据存放地

我们的运营在中国;统计数据在欧盟。

儿童

本站是面向企业的服务,不针对儿童。

变更

我们可能更新本条款。下方日期显示最近一次变更。
